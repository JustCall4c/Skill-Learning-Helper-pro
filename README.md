# Skill-Learning-Helper-pro✨
> 一款专为程序员/办公族打造的「轻量化、无后端、纯前端」知识库 & 快捷备忘录，一站式收纳你的高频代码/快捷键/操作步骤/知识点，高效沉淀你的技术积累 ✍️

## ✨ 核心亮点 | 产品优势
### ✅ 🔥 极致轻量化 · 纯前端无依赖
- 无需部署、无需注册、无需后端服务器，**打开即用**，所有数据**100%存储在浏览器本地**，隐私绝对安全
- 无任何联网行为，断网环境下完全可用，页面秒开，丝滑流畅无加载卡顿
- 单文件部署，仅一个 `.html` 文件，可直接保存本地、放入云盘、部署静态页面，随处可用

### ✅ 📚 多类型笔记一站式收纳，覆盖全场景需求
告别零散的记事本/备忘录，4类核心笔记类型精准匹配办公&学习场景，所有内容结构化管理：
1. **💻 代码片段**：Excel函数、Python代码、SQL语句等高频代码，一键复制，杜绝重复手写
2. **⌨️ 快捷键**：Office/IDE/系统快捷键，自动美化展示，支持上下左右箭头、Ctrl/Alt/Shift等修饰键智能识别
3. **📋 操作步骤**：软件操作流程、配置步骤，按「>」自动分段，步骤可视化，一目了然
4. **✍️ 纯文本笔记**：知识点总结、易错点记录、面试考点，大篇幅内容友好展示，支持换行与格式化

### ✅ 🗂️ 精细化分类+标签双维度检索，高效找内容
#### 1. 多级分类管理
- 自定义创建分类（如：Excel/Python/MySQL/前端/后端），支持自定义分类图标，分类顺序可拖拽调整
- 自动「孤儿笔记救援」：删除分类时自动找回归属丢失的笔记，杜绝内容丢失
- 分类间可快速切换，无感知流畅跳转

#### 2. 标签体系精准检索
- 支持为每条笔记添加多标签（如：面试、基础、易错、高频），标签自动去重聚合
- 「按标签穿透检索」：跨分类查找同标签内容，比如一键筛选所有「面试」相关知识点
- 标签样式美观，支持快速取消筛选，检索效率拉满

### ✅ 📌 超强个性化定制，完全贴合你的使用习惯
#### ✨ 笔记精细化标记
- 「🔥 难点标记」：对易错/难记/重点内容打标，卡片高亮展示，重点内容一眼识别
- 「📌 置顶收藏」：高频笔记一键置顶，置顶笔记单独分区展示，永不被淹没，无需翻找
- 置顶笔记支持拖拽排序，自定义优先级，最常用的内容放最前面

#### ✨ 多维度自定义排序
- ✨ **自定义拖拽排序**：笔记顺序随心拖拽调整，按自己的使用频率排序
- ⏰ 按时间排序：支持「最新添加→最旧」「最旧→最新」双向切换
- 📊 分类专属排序：为每个分类单独配置笔记类型展示优先级，贴合不同分类的使用习惯

#### ✨ 主题&模式自由切换，护眼舒适
- 🌈 **4套精美主题配色**：温柔粉、治愈绿、静谧蓝、大地咖，每套主题均做深浅色适配，颜值拉满
- 🌙 **黑白模式一键切换**：白天浅色护眼，夜间深色模式，自动适配系统色彩偏好，支持快捷键快速切换
- 📖 **沉浸背诵模式**：开启后笔记内容模糊展示，只显示标题，强迫回忆知识点，高效巩固记忆，告别眼过即忘

### ✅ ⏳ 番茄专注时钟 · 学练结合，专注沉淀
- 内置「番茄钟专注功能」，支持 5/10/25/45分钟 四种时长可选，一键开启专注模式
- 自动记录每日专注时长，生成「月度专注热力图」，直观展示你的学习/工作沉淀轨迹
- 专注时长分级上色，不同时长对应不同颜色标记，成就感满满，坚持更有动力
- 专注完成自动触发「烟花彩蛋」，仪式感拉满，正向激励学习热情

### ✅ 📊 成长体系 · 可视化你的积累
- 内置「等级成长系统」，记录笔记数量自动升级，等级进度实时展示
- 每积累5条笔记自动升级，等级与笔记量强绑定，看得见的成长轨迹
- 热力图+等级双维度反馈，你的每一份沉淀都有迹可循

### ✅ 🛡️ 完善的数据安全保障，永不丢失
#### 🔐 本地全量备份/恢复
- 一键导出全量备份文件（`.json`），包含所有笔记、分类、标签、专注时长、排序偏好，**完整无遗漏**
- 一键导入备份文件，支持「合并模式」和「覆盖模式」：检测到本地新增笔记时，可选择保留本地内容或覆盖，杜绝数据丢失
- 备份文件可存至云盘/本地硬盘，换机迁移数据零成本，安全无忧

#### 🐞 内置「捉虫记」Bug记录功能
- 发现产品问题/优化建议，可一键记录至本地Bug清单，支持编辑/删除/清空
- Bug清单本地存储，随时查看待优化项，产品迭代更贴合用户需求

## 🚀 快速使用指南
### ✅ 部署方式（3种任选，全部极简）
1. **本地直接使用**：下载本项目的 `index.html` 文件，双击用浏览器打开即可，无需任何环境配置
2. **静态页面部署**：将 `index.html` 文件上传至任意静态页面托管平台（GitHub Pages/Gitee Pages/Netlify等），直接访问即可
3. **云盘挂载使用**：将文件保存至云盘（阿里云盘/百度网盘等），在线打开即可使用

### ✅ 核心操作流程
#### 1. 新建笔记
- 点击页面右上角「+」按钮，或快捷键 `Ctrl+空格`，打开新建笔记弹窗
- 选择分类、笔记类型，填写标题、核心内容、备注、详细解释、标签
- 可选择「置顶」「难点」标记，点击保存即可，笔记自动存入对应分类

#### 2. 管理笔记
- 笔记卡片支持点击编辑、悬停删除/置顶，操作便捷
- 支持拖拽排序（自定义模式下），调整笔记展示顺序
- 搜索框输入关键词，全局高亮匹配内容，快速检索

#### 3. 分类&标签管理
- 点击分类栏「+」，自定义创建分类，支持选择分类图标，分类顺序可拖拽调整
- 为笔记添加标签后，点击「按标签查看」，可跨分类检索同标签内容
- 标签支持快速取消筛选，灵活切换检索维度

#### 4. 专注学习
- 点击页面顶部「番茄钟」图标，或快捷键 `Alt+F`，打开专注时长选择弹窗
- 选择时长后一键开启，专注结束自动记录时长，生成热力图
- 可在顶部查看月度专注热力图，直观展示学习沉淀

#### 5. 备份&恢复数据
- 点击顶部「保存备份」按钮，一键导出全量备份文件，自动命名带时间戳
- 点击顶部「导入备份」按钮，选择备份文件，支持合并/覆盖两种模式，一键恢复所有数据
